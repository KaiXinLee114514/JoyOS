# ============================================================================
#  rick.txt — 给 JoyOS 的 play 播的一小段"你懂的"riff
#
#  ⚠️ 示意用途,自己改谱!这不是官方谱:只是照着副歌那句的**大致音高**挑出来的
#     16 个音(网上常见的字母谱那种),节奏也是凑的 —— 玩具 OS 的蜂鸣器,
#     听个乐呵就够了,别拿它当视唱练耳的材料。
#
#  怎么改:改音名 / 改时值 / 改 tempo,存盘,然后
#      run PLAY RICK.TXT           播放(要带声音的 QEMU,见 docs/quickstart.md)
#      run PLAY --list RICK.TXT    只把解析结果打出来,不出声
#
#  格式就三样东西:tempo(每分钟几拍)、音名(含八度,升号写 #)、时值(1/2/4/8/16)
# ============================================================================

tempo 140               # 每分钟 140 拍 → 四分音符 ≈ 428 ms

A4  8                   # ne
B4  8                   # ver

B4  8                   # na

F#5 8                   # you
E5  4                   # up
R   8                   # 这里喘口气(休止:不出声,只等一个八分音符)
